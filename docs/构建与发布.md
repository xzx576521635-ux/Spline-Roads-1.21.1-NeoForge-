# 构建与发布

非官方 **1.21.1 NeoForge** 移植版。上游：[ShiraAya/Spline-Roads-Release](https://github.com/ShiraAya/Spline-Roads-Release)。

## 环境

- JDK 21（`JAVA_HOME` 指向它；旧版 JDK 27 会因 class file 71 无法运行 Gradle）
- 项目自带 Gradle Wrapper（8.14.2），首次构建会自动下载
- 可选：把 `DistantHorizons-*.jar` 放进 `libs/`（`compat/dh` 编译需要）

## 构建

```bash
# Windows
gradlew.bat build

# Linux / macOS
./gradlew build
```

产物：`build/libs/splineroads-2.0.jar`

首次构建需要联网（NeoForge / Minecraft artifacts，约 100 个文件）。
如果所在网络访问 `maven.neoforged.net` 失败，可在 `~/.gradle/gradle.properties` 配置代理：

```properties
systemProp.http.proxyHost=127.0.0.1
systemProp.http.proxyPort=7890
systemProp.https.proxyHost=127.0.0.1
systemProp.https.proxyPort=7890
```

## 发布（fork 上游）

1. 在 GitHub 打开上游仓库 → **Fork**，得到 `https://github.com/<你的账号>/Spline-Roads-Release`
2. 在本地仓库添加远端并推一个独立分支：

```bash
git init
git checkout -b 1.21.1-neoforge
git add .
git commit -m "1.21.1 NeoForge port (based on upstream 2.0 + fixes)"
git remote add origin https://github.com/<你的账号>/Spline-Roads-Release.git
git push -u origin 1.21.1-neoforge
```

3. jar 不要提交进仓库；在 GitHub 的 **Releases** 里新建 tag（例如 `v2.0-1.21.1`），
   上传 `build/libs/splineroads-2.0.jar`，说明里写清楚：
   - 对应源码 commit
   - SHA-256
   - 非官方移植、上游版本与许可证

> 注意：上游 2.1.0 起为自定义非商业许可；本仓库基于上游 2.0（MIT）修改，
> 保留原作者署名，注明非官方，不得商业分发。

## 目录约定

```
src/main/java/       源码（com/sora/splineroads/...）
src/main/resources/  assets / data / coremods / META-INF / pack.mcmeta
docs/                开发记录（变更记录、待办与已知问题）
libs/                可选编译依赖（不提交）
```
